# Calmpost app

The Flutter (Android-first) app for Calmpost. See the repo-root `CLAUDE.md` for the design system, game rules and architecture.

```bash
flutter pub get
flutter run              # Android phone
flutter run -d chrome    # browser preview (phone-sized frame)
flutter test
```

Demo controls: long-press Wren on the Home screen to switch the mock bin between healthy, too wet, too dry, curing and ready.
